# One-click Colab run (free T4, no setup)

The fastest way to produce the paper's headline numbers: a ready-made
notebook that runs both arms of the Crafter experiment (27 min each, hard
wall-clock stops) on a free Google Colab T4 — no API keys, no kaggle.json,
just your Google account in the browser.

## How to run (3 clicks)

1. **Upload** [`EBH_JEPA_Crafter_1h.ipynb`](EBH_JEPA_Crafter_1h.ipynb) to
   [colab.research.google.com](https://colab.research.google.com)
   (File → Upload notebook), or copy the file's contents into a new
   notebook.
2. **Runtime → Change runtime type → T4 GPU**.
3. **Runtime → Run all** (~55 min). Keep the tab open; the session stays
   busy so it won't idle-disconnect.

The final cell mounts Google Drive and copies the results JSONs to
`MyDrive/ebh_jepa_crafter_results/` (also downloadable from the Files panel).

## After the run

1. Download the two `crafter_*.json` files.
2. Put them in the repo: `results/crafter/`.
3. Fill Table 2 in `papers/neurips2026/neurips2026.tex` with the
   `eval_return` values at 10k / 20k steps.

## Why this notebook exists

The run protocol (`--train-steps 20000`, `--max-seconds 1620` per arm, seed
0, eval every 5k steps) is identical to the Kaggle path in
[`../kaggle/README.md`](../kaggle/README.md); Colab is just the zero-setup
route. The notebook fetches `agent.py` / `train.py` from the repo at run
time, so it always executes the exact code that's committed here.

## Regenerate

The notebook is generated by [`build_notebook.py`](build_notebook.py)
(`python colab/build_notebook.py`) so it never drifts from the cells it
ships — edit the builder, re-run it, commit both.
